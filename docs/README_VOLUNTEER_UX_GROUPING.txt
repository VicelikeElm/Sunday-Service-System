SSS — VOLUNTEER UX GROUPING UPDATE
====================================

The Volunteer Controls are now organized top-to-bottom by how a volunteer
actually uses the system.

1 — SERVICE PREP
  LAUNCH SUNDAY APPS
  RUN PREFLIGHT

2 — AUDIO / VIDEO
  START SERVICE:
    START RECORDING
    START STREAM

  AUDIO SAFETY:
    EMERGENCY MUTE

  END SERVICE:
    STOP STREAM
    STOP RECORDING

The on-screen helper text explicitly reminds the volunteer of the order:
  Start: Recording first, then Stream
  End:   Stream first, then Recording

3 — SERMON
  One full-width rotating chapter button.

4 — VIEW CAMERA
  WORSHIP VIEW
  PASTOR VIEW

ADMIN / TROUBLESHOOTING remains separated at the bottom.

The collapsible two-column Preflight remains above these controls.

This is a UI/layout change only. Recording and streaming are still manual
human-gated actions and are NEVER started automatically.
