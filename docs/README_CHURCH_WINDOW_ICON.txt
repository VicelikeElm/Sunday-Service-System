SSS — CHURCH WINDOW ICON UPDATE
================================

The default Tk/Windows feather icon in the SSS title bar is replaced
with the existing church icon:

  C:\Church\SermonAI\church_shortcut_icon.ico

This applies to:
  - the main Sunday Service System window
  - Admin / Troubleshooting windows

INSTALL
-------
Close SSS.

Copy these files into:
  C:\Church\SermonAI

and overwrite sunday_mode.py:
  sunday_mode.py
  church_shortcut_icon.ico

Then reopen SSS.
