SSS — QUIETER POST-SERVICE NOTIFICATIONS
========================================

The technical Post-Service Review popup that appeared every time SSS opened
has been removed for normal waiting/review conditions.

NORMAL WAITING / REVIEW
-----------------------
Things such as:

  Recording still stabilizing
  Transcript still processing
  Sermon AI waiting
  Chapter verification waiting
  YouTube waiting
  Planning status from another service date
  Thumbnail handoff prepared

NO LONGER create a popup.

They remain visible in:

  SYSTEM STATUS > AFTER SERVICE

and a short note is written to the Sunday Log.


COMPLETE
--------
A completed after-service workflow also no longer creates a popup every time
SSS opens.

SYSTEM STATUS will show the post-service state, and the Sunday Log says:

  After-service work is complete. Safe to shut down.


WHEN A POPUP CAN STILL APPEAR
-----------------------------
SSS keeps one important exception:

If the LOCAL SUNDAY RECORDING appears to have a real problem such as:

  recording missing
  recording not found
  recording failed
  corrupt / unreadable recording
  recording file not growing

SSS can still show a simple warning:

  Check Sunday Recording

That is kept because a recording problem may need immediate attention.


RESULT
------
Routine post-service information is quiet and visual.

Popup = only something that may require immediate action.
Yellow System Status = something to review when convenient.
