SSS — CENTER-ONLY TOOLTIPS
============================

The floating hover popup has been removed.

Hovering over a status, button, workflow heading, audio meter, or Admin
control now ONLY updates the fixed:

  Tooltip:

help area in the middle of the SSS window.

The fixed Tooltip area remains locked to two lines, so the SSS layout does
not move when the explanation changes.

Clicking a System Status item still shows its current technical detail in
that same Tooltip area.

No configuration files are included or changed.

INSTALL
-------
Close SSS.

Copy:
  sunday_mode.py

into:
  C:\Church\SermonAI

and overwrite the existing file.
