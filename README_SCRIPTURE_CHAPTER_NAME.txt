SSS — SCRIPTURE AS THE CHAPTER NAME
===================================

The reading/reference chapter now uses the actual weekly Scripture text
from the pastor's Gmail sermon plan.

Example:

  BEFORE:
    Reference

  NOW:
    Matthew 12:43-50

The rotating sequence becomes:

  Prayer
  Matthew 12:43-50
  Pastor Point 1
  Pastor Point 2
  ...
  Ending Prayer
  Benediction

The Additional Chapter Hotkeys sync uses the same Scripture text while
preserving the existing Reference hotkey ID/binding where possible.

If the sermon plan has no Scripture for some reason, the system safely
falls back to the generic name "Reference".
