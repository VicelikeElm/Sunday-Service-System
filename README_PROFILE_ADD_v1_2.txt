SSS PROFILE LAYER v1.2 — ADD PROFILE

Main SSS now shows:

  Profile: [ Baptist Church of Perry ▼ ] [ ADD PROFILE ] [ MANAGE ]

ADD PROFILE opens a small dialog. Enter a church/profile name and choose
CREATE & SELECT.

The new profile immediately appears in the dropdown and becomes active.

This is still compatibility mode:
creating or switching profiles does NOT change OBS, Presenter, MIDI, PTZ,
recording, streaming, sermon automation, chapters, lower thirds, audio,
YouTube, Planning, or Sermon AI.

The standalone Profile Manager also now includes NEW PROFILE.

Duplicate names are safe: SSS creates a different internal ID instead of
overwriting the existing profile.

INSTALL:
Close SSS and copy these into C:\Church\SermonAI:
  sunday_mode.py
  sss_profile.py
  sss_profile_manager.py

No live configuration files are included or changed.
